# 🇫🇷 French Vocabulary Tester

**French Vocabulary Tester** — Android-приложение для изучения и проверки знаний французской лексики. Приложение позволяет тренировать перевод французских слов и выражений на русский язык, проходить тестирование и отслеживать результаты.

---

## Основные возможности

-  **Банк вопросов** — более 100 французских слов и выражений с вариантами перевода.
-  **Случайная выборка** — 10 случайных вопросов для каждой попытки.
-  **Ввод ответов** — возможность самостоятельно вводить перевод на русском языке.
-  **Проверка ответов** — автоматическое сравнение введённого ответа с допустимыми вариантами перевода.
-  **Визуальная индикация** — цветовое отображение правильных и неправильных ответов.
-  **Подсчёт результатов** — начисление баллов за правильные ответы и отображение итоговой оценки.
-  **Новая попытка** — возможность повторно пройти тест с новой подборкой вопросов.

### Особенности проверки ответов

При проверке пользовательского ответа учитываются следующие условия:

- Регистр букв не имеет значения.
- Пробелы в начале и конце ответа удаляются.
- Буквы «ё» и «е» считаются равнозначными.
- Ответ сравнивается со всеми допустимыми вариантами перевода конкретного вопроса.

## Архитектура приложения

В приложении используется архитектурный подход **MVVM (Model – View – ViewModel)**, позволяющий разделить данные, пользовательский интерфейс и логику обработки действий пользователя.

### Model — модель данных

Отвечает за хранение вопросов, ответов и состояния отдельных карточек.

| Класс / объект | Описание |
|:---|:---|
| `FrenchQuestion` | Модель вопроса: французское слово и набор допустимых переводов |
| `FrenchQuestionDatabase` | Банк французских слов и выражений |
| `CardData` | Данные карточки и логика проверки правильности ответа |
| `CardState` | Состояние карточки, доступность ввода и цветовая индикация |

### View — пользовательский интерфейс

Реализован с использованием Jetpack Compose.

| Файл | Описание |
|:---|:---|
| `MainActivity.kt` | Главный экран приложения, отображение вопросов, прогресса и результатов |
| `ui/Components.kt` | Composable-компонент карточки вопроса и Preview |
| `ui/theme/Color.kt` | Цветовая схема |
| `ui/theme/Theme.kt` | Тема приложения |
| `ui/theme/Type.kt` | Типографика |

### ViewModel — логика приложения

`MainViewModel.kt` отвечает за управление процессом тестирования:

- Формирование случайной подборки из 10 вопросов.
- Обработку пользовательского ввода.
- Приём и сохранение ответов.
- Переход между вопросами.
- Подсчёт правильных ответов.
- Определение завершения тестирования.
- Запуск новой попытки.

## Принцип работы приложения

1. **Инициализация.** При запуске приложения из общего банка выбираются 10 случайных вопросов без повторений.
2. **Отображение вопроса.** Пользователю показывается французское слово или выражение.
3. **Ввод ответа.** Пользователь самостоятельно вводит перевод на русском языке.
4. **Проверка.** При нажатии на кнопку проверки ответ сохраняется и сравнивается с допустимыми вариантами.
5. **Результат.** Карточка блокируется от повторного ввода и меняет цвет:
   - 🟢 Зелёный — ответ правильный.
   - 🔴 Красный — ответ неправильный.
6. **Переход.** Пользователь переходит к следующему вопросу. Предыдущие карточки остаются доступными для просмотра.
7. **Завершение.** После ответа на все 10 вопросов отображается итоговое количество набранных баллов.
8. **Повторное тестирование.** Пользователь может начать новую попытку с другой случайной подборкой вопросов.
